1. 快速开始

项 说明
Base URL 本站地址，例如 https://vp.735678.xyz（不要带末尾 /）
API Key 控制台创建的 token，格式一般为 sk-...
鉴权头 Authorization: Bearer <API Key>
模型列表 GET /v1/models（返回当前 token 可用模型）
分组 只绑定在 token 上；请求体 不要 传 group
Content-Type JSON 请求用 application/json 
export NEWAPI_BASE_URL="https://vp.735678.xyz"
export NEWAPI_API_KEY="sk-xxxxxxxx"

与官方 New API 的路径对照

能力 官方兼容路径 本站 说明
图片生成 POST /v1/images/generations ✅ OpenAI Images；可带参考图 image
视频（OpenAI Videos） POST /v1/videos · GET /v1/videos/{id} · GET /v1/videos/{id}/content ✅ 推荐 异步：创建 → 轮询 → 下载
视频（New API 通用） POST /v1/video/generations · GET /v1/video/generations/{id} ✅ 与官方通用视频接口一致
素材库 POST /pg/assets · POST /v1/sd/assets · GET /v1/sd/assets/{id} ✅ 部分分组 video-dddd 等要求 asset://
把 OpenAI / New API 兼容客户端的 Base URL 改成本站、 API Key 改成本站 token 即可调用。分组模型表、价格与参数能力详见 统一图片与视频 API 分页。

2. 图片生成

POST /v1/images/generations

同步接口：返回前等待生成完成。客户端读取超时建议 ≥ 300 秒。

核心字段

字段 类型 必填 说明
model string 是 模型名，以 GET /v1/models 为准
prompt string 是 提示词
size string 否 如 1024x1024、2K、auto
n integer 否 生成张数；接入建议先用 1
quality string 否 low / medium / high（模型支持时）
background string 否 opaque / transparent（模型支持时）
image string 或 string[] 否 参考图：HTTPS、Base64 或 data URL
input_reference string 或 string[] 否 image 的兼容别名
watermark boolean 否 部分模型支持
response_format string 否 url（推荐）或 b64_json

响应示例

{
  "created": 1783866456,
  "data": [
    { "url": "https://example.com/result.png" }
  ]
}

response_format: "b64_json" 时使用 b64_json 字段。url 通常有时效，请尽快下载并自行持久化。

curl：文生图

curl "$NEWAPI_BASE_URL/v1/images/generations" \
  -H "Authorization: Bearer $NEWAPI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemini-3-pro-image-preview",
    "prompt": "a cat on the moon, cinematic lighting",
    "size": "1024x1024",
    "n": 1,
    "response_format": "url"
  }'

curl：多参考图

  -H "Authorization: Bearer $NEWAPI_API_KEY" \

      "https://example.com/ref-1.png",
      "https://example.com/ref-2.png"

OpenAI Python SDK

from openai import OpenAI

client = OpenAI(
    api_key="sk-xxxxxxxx",
    base_url="https://vp.735678.xyz/v1",
)

resp = client.images.generate(
    model="gpt-image-2",
    prompt="a red apple on a white table",
    size="2048x2048",
    n=1,
    response_format="url",
)
print(resp.data[0].url)

3. 视频生成（推荐 OpenAI Videos）

官方 New API 与 OpenAI Videos 对齐。本站推荐下列三件套：

步骤 方法 路径 说明
创建任务 POST /v1/videos 立即返回任务 ID
查询状态 GET /v1/videos/{task_id} queued / in_progress / completed / failed
下载成片 GET /v1/videos/{task_id}/content 成功后拉取 MP4
轮询间隔建议 5–10 秒；整条链路超时建议 ≥ 600 秒。任务未结束前不要重复提交同一业务请求。

创建任务

POST /v1/videos
字段 类型 必填 说明
model string 是 视频模型名
prompt string 是 提示词
seconds integer / string 否 推荐时长字段（秒）
duration integer / string 否 seconds 别名；勿与 seconds 传不同值
aspect_ratio string 否 如 16:9、9:16、1:1
resolution string 否 如 480p、720p、1080p
images string[] 否 参考图列表
image string 否 单图兼容字段
videos string[] 否 参考视频
audios string[] 否 参考音频（通常不能单独使用）
generate_audio boolean 否 是否生成有声视频
watermark boolean 否 是否水印
first_image + last_image string 否 首尾帧（部分模型；与多模态参考互斥）

创建响应

{
  "id": "video_xxx",
  "object": "video",
  "status": "queued",
  "model": "dreamina-seedance-2-0-mini-hc",
  "progress": 0,
  "created_at": 1783866456
}

# 查询

Python 轮询示例

import time
import requests

BASE = "https://vp.735678.xyz"
KEY = "sk-xxxxxxxx"
H = {"Authorization": f"Bearer {KEY}", "Content-Type": "application/json"}

r = requests.post(
    f"{BASE}/v1/videos",
    headers=H,
    json={
        "model": "dreamina-seedance-2-0-mini-hc",
        "prompt": "a drone shot over mountains",
        "seconds": 4,
        "aspect_ratio": "16:9",
        "resolution": "480p",
    },
    timeout=60,
)
r.raise_for_status()
task_id = r.json()["id"]

while True:
    s = requests.get(f"{BASE}/v1/videos/{task_id}", headers=H, timeout=60)
    s.raise_for_status()
    body = s.json()
    status = body.get("status")
    print(status, body.get("progress"))
    if status == "completed":
        content = requests.get(
            f"{BASE}/v1/videos/{task_id}/content",
            headers={"Authorization": f"Bearer {KEY}"},
            timeout=300,
        )
        content.raise_for_status()
        with open(f"{task_id}.mp4", "wb") as f:
            f.write(content.content)
        break
    if status == "failed":
        raise RuntimeError(body)
    time.sleep(5)

视频分组速查

分组 计费 参考素材传法 备注
video-dddd 按次 仅 asset://素材ID（须先走素材库） 多模态参考能力强
sd-token Token 无素材库；创建时直接传公网 HTTPS（最多 9 图 + 3 视频 + 3 音频；支持首尾帧；勿用 asset://） 提交预扣，完成后按用量结算；Official V3 映射（详见 统一媒体文档 sd-token）
sd-video 按次 公网 HTTPS URL 部分模型支持首尾帧
grok按次 按次 公网 HTTPS URL Grok 图/文生视频（既有）
grok按次-x 按次 公网 HTTPS URL Grok Imagine 1.5 / Grok Video 3（统一 POST /v1/videos）

4. 素材库（video-dddd 等分组）

当 token 绑定的分组要求参考素材为 asset://... 时，不能在 images / videos / audios 里直接塞 HTTPS 链接：

  1. 本地文件 → POST /pg/assets 上传，得到临时 URL
  2. POST /v1/sd/assets 注册素材，得到 data.Id
  3. GET /v1/sd/assets/{id} 轮询至 Status = Active
  4. POST /v1/videos，字段填 asset://{Id}
素材类型 上传 kind 注册 AssetType 写入字段
图片 image Image images
视频 video Video videos
音频 audio Audio audios 
# 1) 上传
curl "$NEWAPI_BASE_URL/pg/assets" \
  -H "Authorization: Bearer $NEWAPI_API_KEY" \
  -F "kind=image" \
  -F "file=@./reference-1.png"

# 2) 注册
curl "$NEWAPI_BASE_URL/v1/sd/assets" \
  -H "Authorization: Bearer $NEWAPI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "URL": "https://vp.735678.xyz/pg/assets/<upload_id>/reference-1.png",
    "Name": "reference_1",
    "AssetType": "Image"
  }'

# 3) 查询至 Active
curl "$NEWAPI_BASE_URL/v1/sd/assets/<asset_id>" \
  -H "Authorization: Bearer $NEWAPI_API_KEY"

# 4) 创建视频
curl "$NEWAPI_BASE_URL/v1/videos" \
  -H "Authorization: Bearer $NEWAPI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "dreamina-seedance-2-0-mini-hc",
    "prompt": "让人物自然转身并看向镜头",
    "seconds": 4,
    "aspect_ratio": "9:16",
    "resolution": "480p",
    "images": ["asset://<asset_id>"],
    "generate_audio": false,
    "watermark": false
  }'
类型必须匹配；音频一般不能单独使用（至少再带 1 图或 1 视频）。先确认素材 Active，再创建视频。

6. 客户端 / 工具对接

通用 HTTP

  1. Base URL = 本站根地址（或带 /v1，视 SDK 是否自动拼接）
  2. Header：Authorization: Bearer sk-...
  3. 图片：POST /v1/images/generations
  4. 视频：POST /v1/videos → 轮询 GET /v1/videos/{id} → GET /v1/videos/{id}/content

OpenAI 官方 SDK

  • base_url 指向本站 .../v1
  • api_key 使用本站 token
  • 图片可用 client.images.generate(...)
  • 视频部分 SDK 版本尚未完整封装：请直接 HTTP 调用 /v1/videos 三件套

Cherry Studio / 桌面客户端

  1. 提供商类型选 OpenAI 兼容
  2. API 地址填本站 Base URL
  3. 密钥填本站 token
  4. 启用本站图片 / 视频模型名（与 /v1/models 一致）

自建后端转发

  • 不要在 body 里写 group；换能力请换 token
  • 图片长请求与视频轮询分别配置超时
  • 对返回 url / 成片 content 本地落盘
  • 错误体可能是 error.message，也可能是顶层 code + message

7. 常见问题

现象 可能原因 处理
401 / 鉴权失败 Key 错误或未带 Bearer 检查 Authorization: Bearer sk-...
模型不存在 / 无可用渠道 token 分组与模型不匹配 GET /v1/models 核对；换绑定对应分组的 token
图片超时 同步生成较慢 超时 ≥ 300s；勿重复连打
视频一直 in_progress 上游排队或生成中 5–10s 轮询；总等待 ≥ 10 分钟再判失败
invalid_images / 素材错误 分组要求 asset:// 却传了 HTTPS，或类型不匹配 走素材库；确认 Active
参考图无效 非公网可达、过大或格式不支持 用公网 HTTPS / Base64；控制张数与大小
body 里传了 group 本站分组只认 token 去掉 group，换 token

8. 接入检查清单

  • 已拿到本站 Base URL 与 token（sk-...）
  • GET /v1/models 能看到目标图片 / 视频模型
  • 图片：POST /v1/images/generations 成功返回 data[].url 或 b64_json
  • 视频：POST /v1/videos 返回 id，轮询至 completed，能下载 content
  • 若使用 video-dddd：素材上传 → 注册 → Active → asset:// 创建成功
  • 客户端超时：图片 ≥ 300s，视频轮询链路 ≥ 600s
  • 未在请求体中传递 group
  • 结果 URL / 成片已自行持久化
