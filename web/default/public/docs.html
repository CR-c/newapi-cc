VP 统一图片与视频 API 文档

用户始终通过 VP 的统一接口生成图片和视频。分组路由、上游鉴权、参数转换、 视频任务映射与结果代理均由平台内部处理。

接入准备 图片生成 视频通用流程 视频参数差异 错误处理

接入准备

在控制台创建 API Key，并将 Key 绑定到需要使用的分组。不同分组开放的模型和计费方式不同。 

export BASE_URL="https://vp.735678.xyz"
read -rsp "API Key: " API_KEY && echo

所有 API 请求使用 Bearer 鉴权：

Authorization: Bearer $API_KEY
请求中的 model 必须属于当前 API Key 可使用的分组。可在控制台的游乐场中先确认分组和模型是否可见。

图片生成

统一规则：所有图片分组和模型均调用 POST /v1/images/generations。API Key 所属分组决定可见模型、单次价格和内部上游；调用方不需要切换 URL 或使用上游密钥。

统一请求字段

字段 类型 说明
model string 必填，当前 API Key 分组内可用的图片模型
prompt string 必填，图片描述或编辑指令
size string 尺寸、比例映射尺寸或 auto，以模型能力为准
n integer 生成数量，默认为 1
quality string 模型支持时可用 low/medium/high
background string 模型支持时可用 opaque/transparent
image string / string[] 可选参考图，支持 HTTP(S) URL、Base64 或 data URL
input_reference string / string[] image 的兼容别名
response_format string url 或 b64_json

64生图分组

模型 价格 分辨率与比例 支持参数
gemini-3-pro-image-preview $0.15/次 固定 2K；标准 10 比例 n、参考图、response_format
gemini-3.1-flash-image-preview $0.10/次 固定 2K；14 比例，支持超长图 n、参考图、response_format
gpt-image-2 $0.10/次 1K/2K/4K、自动、精确尺寸；标准 10 比例 quality、background、n、参考图、response_format

64生图标准比例：

1:1 16:9 9:16 4:3 3:4 21:9 3:2 2:3 5:4 4:5

gemini-3.1-flash-image-preview 额外支持 1:4 1:8 4:1 8:1。经统一图片端点调用时，该分组的两个 preview 图片模型均固定输出 2K，size 仅用于映射最接近的宽高比。参考图最多 14 张。

gpt-image-2 预设与精确尺寸

比例 1K 2K 4K
1:1 1024x1024 2048x2048 2480x2480
16:9 1280x720 2560x1440 3328x1872
9:16 720x1280 1440x2560 1872x3328

宽高均为 16 的倍数时，gpt-image-2 会原样透传精确尺寸，例如 2160x3840。传 size: "auto" 时由内部上游自动决定。

64生图请求示例

curl "$BASE_URL/v1/images/generations" \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemini-3-pro-image-preview",
    "prompt": "一只坐在窗边的橘猫，柔和自然光",
    "size": "1024x1024",
    "n": 1,
    "response_format": "url"
  }'
curl "$BASE_URL/v1/images/generations" \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "一只红苹果放在白色桌面上",
    "size": "2048x2048",
    "quality": "high",
    "background": "opaque",
    "response_format": "url"
  }'

编辑图片

支持图片编辑的模型可调用 POST /v1/images/edits，使用 multipart/form-data 上传图片，或继续使用 JSON 中的 image/input_reference。 

curl "$BASE_URL/v1/images/edits" \
  -H "Authorization: Bearer $API_KEY" \
  -F "model=gpt-image-2" \
  -F "prompt=将背景替换为海边日落" \
  -F "image=@./input.png"

视频通用流程

统一规则：所有视频分组和模型都使用以下三个本站接口。不要根据模型切换 URL，也不要调用任何服务方专用端点。
  1. 调用 POST /v1/videos 创建任务。
  2. 保存响应中的 id。
  3. 调用 GET /v1/videos/{task_id} 轮询状态。
  4. 状态为 completed 后，通过 GET /v1/videos/{task_id}/content 预览或下载。

创建任务

字段 类型 说明
model string 必填，分组内可用的视频模型
prompt string 必填，视频描述
seconds string / integer 视频时长；本站兼容数字和字符串，并按上游要求转换
aspect_ratio string 画面比例，例如 16:9、9:16、1:1
resolution string 清晰度，例如 480p、720p、1080p、4k
images string[] 可选，公网可访问的参考图 URL
videos string[] 可选，模型支持时传参考视频 URL
audios string[] 可选，模型支持时传参考音频 URL
first_image / last_image string 可选，支持首尾帧的模型必须成对传入，且不能与参考素材数组混用
auto_face boolean 可选，仅支持自动人脸处理的模型生效
generate_audio boolean 部分模型支持，是否同时生成音频
watermark boolean 部分模型支持，是否添加水印

创建成功后立即返回公开任务 ID：

{
  "id": "task_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",
  "task_id": "task_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",
  "object": "video",
  "model": "dreamina-seedance-2-0-mini-hc",
  "status": "queued",
  "progress": 0,
  "created_at": 1784003067
}

查询任务

curl "$BASE_URL/v1/videos/$TASK_ID" \
  -H "Authorization: Bearer $API_KEY"
状态 含义 建议
unknown 任务刚提交，尚未首次同步生成状态 继续轮询
queued 已进入队列 继续轮询
in_progress 正在生成 继续轮询
completed 生成完成 读取内容接口
failed 生成失败 读取 error.message

建议每 5 秒查询一次。本站会在内部周期性同步任务状态。

下载视频

curl -L "$BASE_URL/v1/videos/$TASK_ID/content" \
  -H "Authorization: Bearer $API_KEY" \
  -o generated-video.mp4

内容接口支持浏览器视频预览和 Range 请求。即使任务响应包含 metadata.url，也建议统一使用本站内容接口。

  -H "Content-Type: application/json" \
  -d '{
    "model": "grok-image-video",
    "prompt": "海边日落，镜头缓慢向前推进",
    "seconds": 8,
    "aspect_ratio": "16:9",
    "resolution": "720p"
  }'

curl "$BASE_URL/v1/videos" \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "videos",
    "prompt": "参考人物、动作和音乐生成自然流畅的短片",
    "duration": 10,
    "aspect_ratio": "9:16",

上传本地参考素材

本地图片、视频和音频先上传到本站临时素材接口，返回 URL 有效期为 24 小时，再放入视频请求的对应数组。 

curl "$BASE_URL/pg/assets" \
  -H "Authorization: Bearer $API_KEY" \
  -F "kind=image" \
  -F "file=@./reference.png"

kind 可为 image、video 或 audio。响应中的 data.url 可直接填入 images、videos 或 audios。本站会在内部继续转换成各上游需要的素材协议。

计费说明

任务提交时会预扣额度；任务完成后根据 usage.total_tokens、模型倍率、分组倍率和参考图档位重新结算，多扣部分自动退回，少扣部分自动补扣。任务失败会退回预扣额度。

错误处理

HTTP 状态 常见原因 处理方式
400 参数错误、时长或尺寸不受支持 读取响应中的 code 和 message
401 API Key 缺失、无效或已禁用 检查 Authorization 请求头
403 Key 无权使用目标分组或模型 检查 API Key 的分组和模型权限
429 请求频率超过限制 退避后重试
5xx 视频服务或网关暂时不可用 记录请求 ID，稍后重试

时长错误示例：

{
  "code": "invalid_duration",
  "message": "duration must be between 4 and 15 seconds",
  "data": null
}
