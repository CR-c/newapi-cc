VP 统一图片与视频 API 文档

用户始终通过 VP 的统一接口生成图片和视频。分组路由、请求鉴权、参数转换、 视频任务映射与结果代理均由平台自动处理。若你使用官方 New API / OpenAI 兼容客户端接入，请切换到顶部「官方 New API 对接」分页。

接入准备

在控制台创建 API Key，并将 Key 绑定到需要使用的分组。分组决定可用模型、价格和平台路由。 

export BASE_URL="https://vp.735678.xyz"
read -rsp "API Key: " API_KEY && echo

所有 API 请求使用 Bearer 鉴权：

Authorization: Bearer $API_KEY

使用同一把 API Key 查询当前实际可用的模型：

curl "$BASE_URL/v1/models" \
  -H "Authorization: Bearer $API_KEY"
分组只绑定在 API Key 上。生产 API 请求体不要传 group。切换分组时请更换或重新绑定 API Key；请求中的 model 必须来自该 Key 的 GET /v1/models 响应。

当前控制台公开分组为：64生图、生图、dddd-sd-图、grok按次、grok按次-x、video-dddd、sd-token和sd-video。模型与价格可能由管理员调整，以控制台定价页和当前 API Key 的实际返回为准。

图片生成

统一规则：所有图片分组和模型均调用 POST /v1/images/generations。API Key 所属分组决定可见模型和单次价格；调用方不需要切换 URL。

统一请求字段

字段 类型 说明
model string 必填，当前 API Key 分组内可用的图片模型
prompt string 必填，图片描述或编辑指令
size string 尺寸、比例映射尺寸或 auto，以模型能力为准
n integer 生成数量，默认为 1
quality string 模型支持时可用 low/medium/high
background string 模型支持时可用 opaque/transparent
image string / string[] 可选参考图，支持 HTTP(S) URL、Base64 或 data URL
input_reference string / string[] image 的兼容别名
response_format string url 或 b64_json

编辑图片

支持图片编辑的模型可调用 POST /v1/images/edits，使用 multipart/form-data 上传图片，或继续使用 JSON 中的 image/input_reference。 

curl "$BASE_URL/v1/images/edits" \
  -H "Authorization: Bearer $API_KEY" \
  -F "model=gpt-image-2" \
  -F "prompt=将背景替换为海边日落" \
  -F "image=@./input.png"

使用须知

图片生成是同步长请求。客户端读取超时建议不低于 300 秒。请求仍在处理中时不要重复提交，以免生成和扣费两次。
  • 档位（如 2K）与像素（如 2048x2048）二选一，不要混用。
  • 参考图：pro 最多 10 张，lite / 4.5 最多 14 张；接入可先用 n=1 和无参考图测试。
  • 响应使用 data[].url；URL 通常有时效，调用方应及时下载并自行持久化。
  • 演练场选择“图片”、dddd-sd-图 和目标模型即可。

视频通用流程

统一规则：所有视频分组和模型都使用以下三个本站接口，不要根据模型切换 URL。
  1. 调用 POST /v1/videos 创建任务。
  2. 保存响应中的 id。
  3. 调用 GET /v1/videos/{task_id} 轮询状态。
  4. 状态为 completed 后，通过 GET /v1/videos/{task_id}/content 预览或下载。

创建任务

字段 类型 说明
model string 必填，分组内可用的视频模型
prompt string 必填，视频描述
seconds string / integer 推荐的视频时长字段；本站兼容数字和数字字符串，并自动完成格式转换
duration string / integer seconds 的旧版兼容别名；不要同时传入不同值
aspect_ratio string 画面比例，例如 16:9、9:16、1:1
resolution string 清晰度，例如 480p、720p、1080p、4k
images string[] 可选，公网可访问的参考图 URL
videos string[] 可选，模型支持时传参考视频 URL
audios string[] 可选，模型支持时传参考音频 URL
first_image / last_image string 可选首帧 / 尾帧 URL。 sd-video 须成对且不可与参考素材数组混用； sd-token 可单独或成对使用，并计入 9 图上限，可与 images 等同用
auto_face boolean 可选，仅支持自动人脸处理的模型生效
generate_audio boolean 部分模型支持，是否同时生成音频
watermark boolean 部分模型支持，是否添加水印

创建成功后立即返回公开任务 ID，请保存响应中的 id：

{
  "id": "task_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",
  "object": "video",
  "model": "grok-image-video",
  "status": "queued",
  "progress": 0,
  "created_at": 1784003067
}

查询任务

curl "$BASE_URL/v1/videos/$TASK_ID" \
  -H "Authorization: Bearer $API_KEY"
状态 含义 建议
unknown 任务刚提交，尚未首次同步生成状态 继续轮询
queued 已进入队列 继续轮询
in_progress 正在生成 继续轮询
completed 生成完成 读取内容接口
failed 生成失败 读取 error.message

建议每 5 秒查询一次。平台会周期性同步任务状态。

下载视频

curl -L "$BASE_URL/v1/videos/$TASK_ID/content" \
  -H "Authorization: Bearer $API_KEY" \
  -o generated-video.mp4

内容接口用于浏览器预览或下载。即使任务响应包含 metadata.url，也建议统一使用本站内容接口。

Dedicated integration

video-dddd 专区

本栏目只适用于绑定到 video-dddd 分组的 API Key，集中说明 dddd 视频模型、素材库和计费方式。API Key 决定分组，请求体不要传 group。

先确认分组：使用当前 Key 调用 GET /v1/models。响应中应至少包含一个 dreamina-seedance-2-0-* 模型；否则请检查 Key 的分组和模型权限。
不要直接照搬上游原始接口。用户侧只调用本站 POST /v1/videos、GET /v1/videos/{task_id} 和 GET /v1/videos/{task_id}/content。上游文档里的 POST /v1/video/generate、content[].image_url.url、 content[].video_url.url、content[].audio_url.url、 ratio 和 mvt-* 上游任务 ID，会由本站自动转换与映射。

模型与限制

参考素材参数与官方 SD 视频一致：图片走 images，视频走 videos，音频走 audios。

模型 时长 清晰度 参考素材
dreamina-seedance-2-0-fast-hc 4–15 秒 480p/720p 最多 9 张图片 / 3 个视频 / 3 个音频
dreamina-seedance-2-0-hc 4–15 秒 480p/720p/1080p/4k 最多 9 张图片 / 3 个视频 / 3 个音频
dreamina-seedance-2-0-mini-hc 4–15 秒 480p/720p 最多 9 张图片 / 3 个视频 / 3 个音频
时长必须为 4–15 秒。images 超过 9 张返回 400 invalid_images；videos 超过 3 个返回 400 invalid_videos；audios 超过 3 个返回 400 invalid_audios。三个模型都支持 generate_audio 和 watermark。

素材库接入流程

  1. 准备素材 URL

    使用本站上传接口或管理员批准的 HTTPS 素材域名，获得受控的素材 URL。

  2. 创建并查询素材

    注册素材 URL，保存返回的 ID，并等待 Status 变为 Active。AssetType 按素材类型填写 Image、Video 或 Audio。

  3. 生成视频

    将素材写成 asset://<Id>：图片放 images，视频放 videos，音频放 audios。

1. 准备受控素材 URL

本地文件先上传到本站临时素材接口。响应中的 data.url 是可用于下一步的 HTTPS 地址，有效期为 24 小时。 

curl "$BASE_URL/pg/assets" \
  -H "Authorization: Bearer $API_KEY" \
  -F "kind=image" \
  -F "file=@./reference.png"

kind 可为 image、video 或 audio。若使用自有对象存储或 CDN，素材域名必须先由管理员加入可信域名列表；创建视频时不要直接传任意第三方 URL。

多素材规则：每个参考素材都要分别执行上传、创建素材、查询 Active。多图不是一次传多张到 /v1/sd/assets，而是在 /v1/videos.images 中放入最多 9 个 asset:// 素材 ID；视频和音频分别放入 videos、audios，各最多 3 个。

2. 创建素材

创建接口为 POST /v1/sd/assets。接口使用当前 video-dddd API Key 鉴权，并返回仅属于当前账户的本站素材 ID。

POST/v1/sd/assets 
curl "$BASE_URL/v1/sd/assets" \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "URL": "https://vp.735678.xyz/pg/assets/<upload_id>/reference.png",
    "Name": "avatar_front",
    "AssetType": "Image"
  }'
字段 类型 说明
URL string 必填，管理员批准域名下的 HTTPS 素材地址（仅默认 443 端口）
Name string 必填，1–128 个字符的素材名称
AssetType string Image、Video 或 Audio

创建成功响应：

{
  "success": true,
  "data": {
    "Id": "asset-N3w8cK7pQ2mR5tV9xY4zA6bD",
    "base_resp": {
      "status_code": 0,
      "status_msg": "success"
    }
  }
}
保存 data.Id。这是 VP 生成的账户级素材 ID，不是上游 ID。其他用户的素材 ID、上游原始 ID 或未经过本站创建的 asset:// 引用均不可使用。

3. 查询素材

查询接口为 GET /v1/sd/assets/{asset_id}。路径中的 asset_id 使用创建响应里的 data.Id。

GET/v1/sd/assets/{asset_id} 
ASSET_ID="asset-N3w8cK7pQ2mR5tV9xY4zA6bD"

curl "$BASE_URL/v1/sd/assets/$ASSET_ID" \
  -H "Authorization: Bearer $API_KEY"

素材可用时的响应：

{
  "success": true,
  "data": {
    "Id": "asset-N3w8cK7pQ2mR5tV9xY4zA6bD",
    "Status": "Active",
    "AssetType": "Image",
    "Name": "avatar_front",
    "URL": "https://vp.735678.xyz/pg/assets/<upload_id>/reference.png",
    "GroupId": null,
    "CreateTime": "2026-07-04T12:15:34Z",
    "UpdateTime": "2026-07-04T12:15:36Z",
    "base_resp": {
      "status_code": 0,
      "status_msg": "success"
    }
  }
}

建议每 2 秒查询一次，直到 Status 为 Active 后再提交视频任务。若返回 404，请确认素材由当前账户创建，并且查询时仍使用 video-dddd 分组的 API Key。

4. 在视频请求中引用素材

将素材 ID 加上 asset:// 前缀后放入对应字段： Image 素材放 images，Video 素材放 videos，Audio 素材放 audios。本站会校验素材归属和类型，并自动固定到创建该素材的上游渠道。

使用须知

提交时会先预扣，完成后再按实际 Token 重算。 多扣部分自动退回，少扣部分自动补扣，失败任务退回预扣。余额必须能覆盖提交时的预扣额度。
  • 接入测试建议先用 4 秒 + 480p + 无参考，降低等待和消耗。
  • 素材须为服务端与上游可访问的 HTTPS URL；勿使用即将过期的一次性签名链。
  • 建议每 5–10 秒轮询，整体超时不低于 600 秒；不要用高频轮询或重复提交代替等待。
  • 结果 URL 由本站代理，不要依赖或保存上游内部任务 ID。
  • 对外任务状态仍为 OpenAI 视频风格（ queued / in_progress / completed / failed ）。
  • 演练场选择“视频”、sd-token 和该模型即可使用同一参数与计费链路。

本地图片、视频和音频先上传到本站临时素材接口，返回 URL 有效期为 24 小时，再放入视频请求的对应数组。

  -F "file=@./reference.png"

kind 可为 image、video 或 audio。响应中的 data.url 可直接填入 images、videos 或 audios。本站会自动完成素材格式转换。 临时素材 URL 在有效期内可直接访问，请勿上传敏感素材或公开该 URL。

任务结算说明

grok按次、grok按次-x 和 sd-video 按控制台标价按次结算。仅 video-dddd 会在提交时预扣额度，并在任务完成后根据 usage.total_tokens、模型倍率、分组倍率和参考图档位重新结算，多扣部分自动退回，少扣部分自动补扣。任务失败会退回预扣额度。

错误处理

HTTP 状态 常见原因 处理方式
400 参数错误、时长或尺寸不受支持 优先读取 error.message，并兼容顶层 message
401 API Key 缺失、无效或已禁用 检查 Authorization 请求头
403 Key 无权使用目标分组或模型 检查 API Key 的分组和模型权限
429 请求频率超过限制 退避后重试
5xx 视频服务或网关暂时不可用 记录请求 ID，稍后重试

鉴权和分发错误通常使用 OpenAI 风格的 error.message； 视频任务错误可能返回顶层 code 和 message。客户端应兼容这两种错误结构。
