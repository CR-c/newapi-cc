Grok 视频：grok按次

grok-image-video 支持文生、单图和多参考图视频；grok-video-1.5 仅支持单图。使用 POST /v1/videos 创建任务，再用 GET /v1/videos/{task_id} 查询。

curl https://vp.735678.xyz/v1/videos -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" -d '{"model":"grok-image-video","prompt":"海边日落","seconds":"8","size":"1280x720"}'
